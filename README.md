## ✨ Features

- 🚀 **200+ locations** across 11 states of Peninsular Malaysia
- 🎯 **90+ spaceport candidates** pre-analyzed
- 🌐 **Live OpenStreetMap data** — airports, settlements, roads, coastline
- 🌤️ **Live weather integration** — wind speed, gusts, direction from Open-Meteo
- 📊 **8-factor suitability scoring** — elevation, population, coastal access, infrastructure, land, flood risk, latitude, wind
- 🧠 **Agent memory** — learns optimal parameters from past analyses
- 📈 **Site comparison mode** — rank all candidates side-by-side
- 🗺️ **Interactive map** — click any point for instant analysis
- 🛰️ **Satellite view toggle** — see real terrain
- 📋 **Detailed recommendation strategy** — actionable insights with timelines and costs
- ⚡ **Instant results** — geographic rules deliver in 3-5 seconds
- 💾 **24-hour API caching** — fast repeat analyses

## 🎯 Why Peninsular Malaysia for a Spaceport?

Peninsular Malaysia offers strategic advantages for equatorial launches:

| Factor | Advantage |
|---|---|
| **Latitude** | 1-7°N — near equator → Earth's rotation boost = **~460 m/s free velocity** |
| **Long Coastline** | East coast (South China Sea) allows safe eastward launches over ocean |
| **Sparse East Coast** | Pahang, Terengganu, Kelantan have low population → large safety zones |
| **Established Infrastructure** | KLIA, Penang Intl, Senai airports + major ports already exist |
| **Political Stability** | Malaysia is politically stable with strong rule of law |
| **Strategic Location** | Between Southeast Asia, Australia, and the Pacific |
| **Islands Available** | Langkawi, Pangkor, Tioman, Aur for isolated launch sites |

**Near-equatorial launches save 20-30% fuel** compared to mid-latitude sites like Cape Canaveral (28.5°N) or Baikonur (45.6°N).
